## 2. Nombre del proyecto

**PhishLab — Plataforma web para aprender a detectar phishing.**

Una aplicación educativa donde los usuarios podrán practicar cómo identificar correos electrónicos, mensajes y páginas web fraudulentas.

## 3. Qué quiero hacer

Quiero desarrollar una plataforma web de aprendizaje sobre ciberseguridad, centrada principalmente en el phishing y las estafas digitales.

La aplicación mostrará simulaciones de correos electrónicos, SMS y páginas web. El usuario tendrá que decidir si son legítimos o fraudulentos.

Después de cada respuesta, el sistema explicará por qué era correcta o incorrecta y qué señales permiten detectar el engaño.

También habrá diferentes niveles de dificultad, puntuaciones y estadísticas para consultar el progreso.

Para gestionar los usuarios, las simulaciones y los resultados, desarrollaré una API REST conectada a una base de datos.

## 4. Qué problema o necesidad resuelve

El phishing es una amenaza habitual que intenta engañar a las personas para conseguir contraseñas, datos personales o dinero.

Muchas personas no saben identificar los indicios de estos ataques. PhishLab pretende ayudarles a reconocerlos mediante ejercicios prácticos en un entorno seguro.

Esta necesidad se estudiará con más detalle utilizando fuentes como INCIBE y analizando herramientas educativas existentes.

## 5. Para quién

La plataforma estará dirigida principalmente a estudiantes y personas que quieran mejorar sus conocimientos básicos de ciberseguridad.

También podría utilizarse en centros educativos como herramienta complementaria de aprendizaje.
