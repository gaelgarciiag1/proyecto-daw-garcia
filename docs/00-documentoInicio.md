## 2. Nombre del proyecto

**PhishLab — Plataforma web para aprender a detectar phishing.**
Una aplicación educatica donde los usuarios puedan practicar cómo identificar correos electrónicos, mensajes, páginas web fraudulentas...

## 3. Qué quiero hacer

Quiero crear una plataforma web para aprender sobre ciberseguridad, especialmente sobre el phishing y las estafas digitales.

El usuario tendrá que identificar si distintos correos, SMS y páginas web son reales o fraudulentos. Después de cada respuesta, recibirá una explicación.

La aplicación tendrá niveles de dificultad, puntuaciones y estadísticas de progreso. También utilizaré una API REST conectada a una base de datos para gestionar los usuarios y sus resultados.

## 4. Qué problema o necesidad resuelve

El phishing es una amenaza habitual que intenta engañar a las personas para conseguir contraseñas, datos personales o dinero.

Muchas personas no saben identificar los indicios de estos ataques. PhishLab pretende ayudarles a reconocerlos mediante ejercicios prácticos en un entorno seguro.

Esta necesidad se estudiará con más detalle utilizando fuentes como INCIBE y analizando herramientas educativas existentes.

## 5. Para quién

La plataforma estará dirigida principalmente a estudiantes y/o personas con menos idea o conocimiento de informática que quieran mejorar sus conocimientos básicos de ciberseguridad.

También podría utilizarse en centros educativos como herramienta complementaria de aprendizaje.

## 9. Datos y empresas

**¿El proyecto parte de una empresa?** No.

Se plantea como un proyecto educativo propio, sin una empresa real como cliente.

**¿Usará datos personales reales?** No.

Durante el desarrollo se utilizarán cuentas ficticias y datos de ejemplo. Las simulaciones no recogerán contraseñas reales ni enviarán mensajes fraudulentos a terceros.
