# PhishLab — Aprende a detectar el phishing

**Una frase:** Plataforma web educativa que ayuda a los usuarios a identificar correos electrónicos, mensajes y páginas web fraudulentas mediante simulaciones interactivas y seguimiento de su aprendizaje.
